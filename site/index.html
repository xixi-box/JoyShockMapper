用 DualSense / DualShock 4 / Joy-Con / Pro Controller 玩游戏，支持陀螺仪瞄准、 完整按键映射与文本配置工作流 —— 现在带上了现代图形界面。

核心特性

保留 JoyShockMapper 的映射核心与文本配置格式，并提供现代桌面操作界面。

🎮

手柄控制台界面

借鉴 JoyHarness 的深色手柄控制台：首页直接展示手柄示意图、键位连线与当前映射。

🖱️

陀螺仪瞄准

按住启用陀螺仪鼠标移动，灵敏度、加速与平滑范围常用调节直接对应原生参数。

⌨️

单击 / 双击 / 多键映射

单击与双击动作可分别映射，支持单键与多键组合快捷键输出。

💾

每设备自动恢复

根据控制器身份自动保存并恢复映射，换设备即插即用。

🌐

中英文即时切换

默认简体中文，右上角一键切换 English / 中文，无需重启。

🖥️

单文件便携 EXE

Tauri/Rust 单可执行文件，C++ 核心静态链接进同一进程，无需安装。

🧩

兼容文本配置工作流

OnStartup.txt / OnReset.txt / GyroConfigs / AutoLoad 原有工作流保持可用。

🪟

托盘与开机自启

最小化到系统托盘，映射与陀螺仪后台继续运行；开机自启无需管理员权限。

Rust · Tauri

自行构建

Windows x64 环境需要 Visual Studio 2022 C++、CMake、Ninja、Node.js 与 Rust。

powershell -ExecutionPolicy Bypass -File .\rust\build-portable.ps1

构建结果写入仓库根目录 JoyShockMapper.exe，同时生成 out/portable/JoyShockMapper.exe 供 CI 与发行打包。
