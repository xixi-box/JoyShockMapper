JOY-CON

Joy-Con 外部映射工具

把任天堂 Joy-Con 变成 PC 上最灵活的无线输入设备。

🎯

陀螺仪瞄准

按住 ZL 启用陀螺仪鼠标移动，精细/快速灵敏度、加速与低速平滑对应原生参数。

⌨️

单击 / 双击 / 多键

单击与双击动作分别映射，支持单键与多键组合快捷键输出。

💾

左右 Joy-Con 独立配置

按控制器身份自动保存并恢复映射；有序列号按序列号区分，否则左右侧分别共享。

🔗

虚拟手柄 / 键盘输出

SDL3 原生轮询，经 ViGEm 输出 Xbox/DS4 虚拟手柄，或直接模拟键盘鼠标。

🔋

接收器与 TX 电量

实时显示接收器、TX1 电量与充电状态，直观的示意图 + 数字。

📶

输入电平与连接状态

输入电平、TX1 断连/重连、接口被占用自动重试，状态一目了然。

🛡️

零侵入设计

仅匹配 VID 2CA3 / PID 4011，只读 Interface 6；不动 configuration、不切换 alt setting、不分离驱动，音频通道不受影响。

🎛️

白名单字段回写

仅对协议有明确命令、取值编码且型号匹配的字段显示控件；界面等待状态包回读确认，不伪造新值。

📋

完整设备信息

固件、设备名称、录制状态、增益、音色、降噪、低切等真实字段，未读到的值绝不凭空补值。

FEATURES

更多特性

保留 JoyShockMapper 的映射核心与文本配置格式，并提供现代桌面操作界面。

🎮

手柄控制台界面

借鉴 JoyHarness 的深色手柄控制台：首页直接展示手柄示意图、键位连线与当前映射。

🌐

中英文即时切换

默认简体中文，右上角一键切换 English / 中文，无需重启。

🖥️

单文件便携 EXE

Tauri/Rust 单可执行文件，C++ 核心静态链接进同一进程，无需安装。

🧩

兼容文本配置

OnStartup.txt / OnReset.txt / GyroConfigs / AutoLoad 原有工作流保持可用。

🪟

托盘与开机自启

最小化到系统托盘，映射与陀螺仪后台继续运行；开机自启无需管理员权限。

🔘

菱形快捷键

复制/剪切/粘贴、系统截图、定位输入控件等特殊功能，普通按键由 C++ 实时执行。
